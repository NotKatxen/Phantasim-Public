# 🌌 Phantasim Virtual World & Forum

A modern, highly responsive 2D virtual world and community forum featuring real-time, in-browser interaction.

## 🛠 Tech Stack

*   **🐙 GitHub:** Central repository for code storage and CI/CD triggers.
*   **⚡ Vercel:** Global cloud hosting for automatic, instant deployments.
*   **🔥 Firebase:** Powers secure Auth and real-time database functions.

---

## 🚀 Key Features

*   **🔐 Accounts:** Secure user registration and login.
*   **🔥 Economy:** Daily logins (+10 Coins), Shop, and Trading.
*   **👕 2D Avatar Editor:** Custom character appearance.
*   **💬 Community:** Real-time forums and social networking.
*   **📈 Simulation:** In-app stock market simulation.
*   **🎨 Theme Toggle:** Light/Dark mode options.

---

## 📦 Local Setup

```bash
git clone https://://github.com.git
cd phatasim-website
npm install
# Add your .env file with Firebase credentials
npm run dev
```

---

## 🌐 Automatic Deployment

Push updates to **GitHub** to trigger an automatic **Vercel** build, pushing changes to the live URL instantly.
